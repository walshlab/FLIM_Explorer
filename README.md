# FLIMExplorer

Interactive Dash-based tools for analyzing FLIM datasets.

## Installation

Clone the repository and install in editable mode:

```bash
git clone https://github.com/YOURUSERNAME/flim-explorer.git
cd flim-explorer
pip install -e .

## Run the main application

python -m flimexplorer.app

## Run the IO table generator tool

python -m flimexplorer.tools.generate_input_table
